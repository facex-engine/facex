# FaceX. 154 математические задачи с решениями

Здесь номер означает математическую постановку, а не коммит, тест или обещание ускорения. Примеры с заданными числами иллюстрируют формулы. Реальные FAR, задержки и распределения ошибок камер должны измеряться отдельно. Для распознавания обозначаем через q единичный вектор запроса, через x — единичный шаблон, через s=q·x — косинусную оценку. FAR — вероятность ложного допуска при заданном протоколе.

## 1–6. Как правильно выровнять лицо по ориентирам

**1. Найти поворот, масштаб и перенос при неодинаковой точности точек.** Минимизируем сумму wᵢ|yᵢ−czᵢ−t|², представив точки комплексными числами. Производная по t даёт t=ȳ−c z̄. После центрирования нормальное уравнение даёт c=Σwᵢ conj(zᵢ−z̄)(yᵢ−ȳ)/Σwᵢ|zᵢ−z̄|². Масштаб равен |c|, угол — arg(c). Средние взвешенные; сумма весов и знаменатель должны быть положительными. При одинаковых весах получаем преобразование из src/align.c. Для пяти точек с разной дисперсией ошибки наблюдения в y выбор wᵢ=1/σᵢ² соответствует взвешенному МНК.

**2. Когда оценка поворота и масштаба плохо обусловлена?** Обозначим S=Σwᵢ|zᵢ−z̄|². При фиксированных исходных точках и ошибках целевых точек eᵢ числитель изменения c равен Σwᵢ conj(zᵢ−z̄)eᵢ. По Коши–Буняковскому |Δc|≤√(Σwᵢ|eᵢ|²/S). Если S уменьшилось в 16 раз при том же бюджете шума, граница ошибки выросла в четыре раза. Одного числа успешно найденных ориентиров недостаточно для оценки устойчивости.

**3. Как проверить выпадение каждого ориентира без пяти новых полных подгонок?** Накопить W=Σw, Z=Σwz, Y=Σwy, U=Σw|z|², V=Σw conj(z)y. Тогда S=U−|Z|²/W и c=(V−conj(Z)Y/W)/S. Вычитание пяти слагаемых одной точки даёт решение без этой точки за O(1); все варианты — за O(n). При больших абсолютных координатах сначала переносим начало вблизи лица, иначе разность в S теряет точность.

**4. Насколько ошибка прямого преобразования сдвигает выборку пикселей?** При y=cz+t, возмущениях δc,δt и |δc|<|c| обратное отображение даёт |z′−z|≤(|δt|+|z||δc|)/(|c|−|δc|). Это следует непосредственно из z′−z=−(δt+zδc)/(c+δc). При |z|≤50, масштабе 1, |δc|≤0,01 и |δt|≤0,5 пикселя сдвиг не превосходит 1,011 пикселя.

**5. Какую пару точек брать при аварийном выравнивании по двум ориентирам?** Если ошибки в двух целевых точках независимы и имеют одинаковую дисперсию, c=(y₂−y₁)/(z₂−z₁), а дисперсия оценки пропорциональна 2σ²/|z₂−z₁|². Выбираем самую удалённую достоверную пару. Удвоение расстояния уменьшает дисперсию вчетверо. Для разного качества надо максимизировать |z₂−z₁|²/(σ₁²+σ₂²).

**6. Сколько яркости теряется при субпиксельной ошибке?** Внутри билинейной ячейки производная по x — выпуклая комбинация двух горизонтальных разностей, аналогично для y. Поэтому |ΔI|≤Gₓ|Δx|+Gᵧ|Δy|, где G — максимальные модули соответствующих разностей на пути. Для Gₓ=20, Gᵧ=10 и сдвига (0,1; 0,2) получаем не более четырёх уровней яркости, или 4/127,5 после нормировки. На границе заполнения кадра нужна отдельная оценка скачка.

## 7–12. Геометрия детектора, плиток и рамок

**7. Как получить наибольший масштаб при дискретном бюджете YuNet?** При c столбцах по 32 пикселя и B ячейках доступно floor(B/c) строк. Масштаб равен min(32c/w,32 floor(B/c)/h). Первый аргумент растёт, второй убывает, поэтому максимум достигается в точке пересечения или у соседнего целого c. Двоичный поиск даёт O(log C) вместо O(C). После него применяется ограничение длинной стороны. Это обоснование текущего rectangle_shape.

**8. Увидит ли детектор лицо заданного размера после уменьшения?** Для горизонтального размера d нужно d·rw/w≥m, для вертикального d·rh/h≥m. При кадре 1920×1080 и содержимом 832×468 масштаб в обоих направлениях 13/30. Чтобы получить хотя бы 16 пикселей, сторона исходного лица должна быть не меньше ceil(16·30/13)=37 пикселей. Это необходимое геометрическое условие, не гарантия обнаружения.

**9. Какое перекрытие плиток гарантирует, что лицо не разрежет стык?** Начало объекта длины d помещается в плитку длины T на отрезке длины T−d. Чтобы между допустимыми отрезками не было разрывов, шаг H≤T−d, то есть перекрытие ≥d. Для T=640 и d=96 максимальный шаг 544. Условие по обеим осям и последняя плитка у границы обеспечивают геометрическое покрытие.

**10. Как распределить ограниченное время повторной детекции между областями?** Для непересекающихся областей с независимыми аддитивными выгодами gᵢ и целочисленными стоимостями cᵢ решаем рюкзак: Fᵢ(b)=max(Fᵢ₋₁(b),gᵢ+Fᵢ₋₁(b−cᵢ)) при допустимой стоимости. При бюджете 10, стоимостях (6,5,5) и выгодах (10,8,8) оптимальны две последние области: 16 вместо 10 у жадного выбора по отношению. Для перекрывающихся областей выгоду общих лиц нельзя сложить дважды.

**11. Какое движение рамки само по себе разрывает трек по IoU?** Для двух равных рамок ширины w с одним горизонтальным смещением d≤w имеем IoU=(w−d)/(w+d). Условие IoU≥τ эквивалентно d≤w(1−τ)/(1+τ). При w=80 и τ=0,35 граница около 38,52 пикселя. При изменении масштаба или движении по диагонали эта одномерная граница уже не точна.

**12. Когда пару положительных рамок можно исключить из NMS до расчёта пересечения?** Если площади A≤B, то пересечение ≤A, объединение ≥B. Следовательно IoU≤A/B. При строгом подавлении IoU>τ сравнение можно пропустить, когда A≤τB. При A=40, B=100 и τ=0,4 даже вложенная рамка не пересекает строгий порог. Для реализации в плавающей точке нужна осторожность на границе равенства.

## 13–18. Численная математика ядра

**13. Какова безопасная глубина знакового INT8 dot-product?** Для значений от −128 до 127 наибольший положительный член равен 16 384. При int32 и нулевом смещении K≤floor((2³¹−1)/16 384)=131 071. С известным смещением b достаточна граница K·16 384+|b|≤2³¹−1. Для схемы с промежуточной компенсацией надо отдельно проверить каждую промежуточную сумму.

**14. Как перенести ошибки квантования на скалярное произведение?** Раскрытие (a+e)·(b+f) даёт |Δ|≤‖a‖‖f‖+‖b‖‖e‖+‖e‖‖f‖. Для единичных векторов и ‖e‖,‖f‖≤0,01 оценка равна 0,0201. Для неодинаковых норм весов и активаций надо сохранить первые два множителя; одна средняя ошибка по компонентам такой гарантии не даёт.

**15. Какой масштаб оптимален для уже выбранных целых кодов?** Минимизация Σ(wᵢ−sqᵢ)² по s даёт s=(q·w)/(q·q). При требовании s≥0 берём max(0,s); если q=0, масштаб на результат не влияет. Пример w=(0,9; 2,1), q=(1; 2) даёт 1,02. Это точный шаг оптимизации при фиксированных кодах. После их пересчёта требуется новая проверка ошибки.

**16. Когда линейный слой и BatchNorm можно слить точно?** При фиксированных статистиках вывода α=γ/√(v+ε). Для y=Wx+b получаем W′=diag(α)W и b′=α⊙(b−μ)+β. Результат алгебраически тот же, а отдельный проход исчезает. Если после слияния веса квантуются, ошибку повторного округления измеряют отдельно. Эта формула не заменяет LayerNorm с зависимыми от входа статистиками.

**17. При каком ранге факторизация проекции действительно уменьшает число умножений?** Матрица m×n стоит mn на одну строку. Два множителя ранга r стоят r(m+n); экономия при r<mn/(m+n). Для 64×256 имеем r<51,2. При r=38 стоимость 12 160 вместо 16 384, экономия 25,78%. Это счёт операций; фактическая задержка зависит от ядра и памяти.

**18. Когда выгодно разреженное вычисление геометрии?** Пусть N позиций, m прошли порог, U уникальных соседей 3×3, стоимость проекции P, регрессии R, сборки списка H. Плотный путь стоит N(P+R), разреженный — UP+mR+H, если проекция соседа вычисляется один раз. Для N=1000, m=20, U=120, P=4, R=3 получаем 540+H против 7000; безубыточность при H<6460 условных единиц. При повторном вычислении соседей U заменяется фактическим числом обращений, вплоть до 9m.

## 19–24. Как объединять несколько фотографий человека

**19. Какой единичный шаблон минимизирует суммарное квадратичное расстояние до видов?** Раскрытие Σwᵢ‖u−xᵢ‖² при ‖u‖=‖xᵢ‖=1 сводит задачу к максимуму u·r, r=Σwᵢxᵢ. По Коши оптимум u=r/‖r‖. При r=0 единственного решения нет; для зачисления разумно вернуть неопределённость.

**20. Как выбрать лучшую именно наблюдавшуюся фотографию без матрицы n×n?** В предыдущей задаче ограничиваем u множеством xⱼ. Тогда j*=argmaxⱼ xⱼ·r. Один проход строит r, второй оценивает все виды. Это O(nd) вместо O(n²d), при той же взвешенной косинусной целевой функции.

**21. Как оценить разброс видов без перебора всех пар?** При pᵢ≥0 и Σpᵢ=1 имеем Σᵢⱼpᵢpⱼ‖xᵢ−xⱼ‖²=2(1−‖Σpᵢxᵢ‖²). Если длина среднего 0,8, среднее квадратичное расстояние двух независимых выборок видов равно 0,72. Это проверяемый смысл показателя согласованности шаблона.

**22. Сколько независимых фотографий фактически осталось после взвешивания?** При одинаковой дисперсии независимых ошибок дисперсия взвешенного среднего равна σ²Σpᵢ². Эффективный размер n_eff=1/Σpᵢ². При весах (0,8; 0,1; 0,1) получаем 1,515 вместо трёх. Для кадров одного видео корреляция дополнительно уменьшает информацию.

**23. Какие веса оптимальны при коррелированных ошибках снимков?** Минимизируем pᵀΣp при 1ᵀp=1. Для положительно определённой ковариации множитель Лагранжа даёт p=Σ⁻¹1/(1ᵀΣ⁻¹1). Для независимых дисперсий 1 и 4 веса 0,8 и 0,2, дисперсия 0,8 вместо 1,25 при равных весах. Если нужны неотрицательные веса и формула дала отрицательные, решаем квадратичную задачу на симплексе.

**24. Насколько один плохой вид может повернуть хороший шаблон?** Пусть сумма хороших видов имеет длину R, а норма добавки ≤e<R. Максимальный угол между r и r+δ задаёт касательная из начала к шару радиуса e вокруг r: sin θ≤e/R. Для R=4 и e=1 угол ≤14,48°. При e≥R направление может стать неопределённым.

## 25–30. Поиск среди десятков тысяч шаблонов

**25. Как перевести косинусный порог в радиус поиска?** Для единичных векторов ‖q−x‖²=2−2s. Порог s≥0,8 эквивалентен радиусу ≤√0,4≈0,63246. Это позволяет проверять косинусный поиск эталонным поиском по евклидову расстоянию.

**26. Как гарантировать, что приближённый рейтинг не потеряет точный top-k?** Если |ŝᵢ−sᵢ|≤ε, а c — kth приближённая оценка, любой объект с ŝᵢ<c−2ε имеет точную оценку <c−ε; как минимум k объектов имеют точную оценку ≥c−ε. Поэтому сохраняем все ŝᵢ≥c−2ε, включая равенство. Разность 2ε учитывает две независимо возможные ошибки, одной ε недостаточно.

**27. Когда можно завершить dot-product после части координат?** Пусть P — уже посчитанное произведение, a и b — нормы непросмотренных хвостов. Тогда s≤P+ab. При P=0,35, a=0,4, b=0,5 верхняя граница 0,55; кандидат не достигнет текущей пятой оценки 0,56. Равенство на пороге требует учёта правила сортировки совпадений.

**28. Как отбросить целую сферическую группу?** Пусть все шаблоны находятся на угловом расстоянии ≤r от единичного центра c, а θ=arccos(q·c). По неравенству треугольника максимальный возможный косинус равен не более cos(max(0,θ−r)). При θ=60°, r=15° граница 0,7071; группа не улучшит порог 0,75.

**29. Как оценить ошибку INT8-кандидата из шага квантования?** Если нет клиппинга и каждая из D координат округлена с шагом Δ, то ‖e‖≤√D·Δ/2. Для единичного запроса |q·e|≤√D·Δ/2. При D=512 и Δ=0,001 ошибка ≤0,01132. Это граница до повторной нормировки; если квантовали обе стороны, используем №14.

**30. Когда результат проходной устойчив и по оценке, и по отрыву?** Пусть все оценки известны с ошибкой ε. Для включающего порога t и минимального отрыва m достаточны ŝ₁−ε≥t и ŝ₁−ŝ₂−2ε≥m, причём нижний отрыв должен быть строго положительным для единственности. При (0,81; 0,76), ε=0,01, t=0,79, m=0,025 оба условия выполнены. Для меньшего отрыва нужен точный пересчёт или отказ от решения.

## 31–36. Проверка точности и цена ложного допуска

**31. Как посчитать AUC при совпадающих оценках?** AUC=P(S₊>S₋)+½P(S₊=S₋). Для положительных оценок (0,8; 0,5) и отрицательных (0,5; 0,2) есть три победы и одна ничья; AUC=0,875. Сортировка и объединение одинаковых оценок дают тот же результат без полного попарного массива.

**32. Как выбрать порог при заданном эмпирическом FAR?** При n₋ отрицательных парах и бюджете f допускается не более floor(f n₋) ложных допусков. Сортируем оценки по убыванию и добавляем целые группы равных значений. Выбираем допустимую группу с максимальным числом истинных допусков, при равенстве — меньший FP. Состояние «отклонить всех» всегда достижимо. Это выбор на калибровке; проверка выполняется на независимой выборке.

**33. Сколько отрицательных сравнений нужно, чтобы ноль ошибок имел смысл?** При независимых испытаниях с фиксированным порогом P(0 ошибок)=(1−p)ⁿ. Односторонняя верхняя граница 95% равна 1−0,05^(1/n). Для границы ≤10⁻⁴ нужно ceil(log(0,05)/log(0,9999))=29 956 отрицательных сравнений без ошибок. Подбор порога на этих же сравнениях нарушает предпосылку.

**34. Как меняется риск при поиске по всей базе?** Если вероятность ложного совпадения с одной записью p, то без предположения независимости P(хотя бы одно)≤min(1,Np). При независимости и одинаковом p точное значение 1−(1−p)ᴺ. Для N=10 000, p=10⁻⁵ это соответственно ≤10% и примерно 9,52%. У реальной базы надо измерять ложные идентификации целыми поисковыми запросами.

**35. Как получить порог из цены ошибки и частоты посетителей?** Для плотностей оценки f₁ при своём и f₀ при чужом, априорной доли своих π, сравниваем отношение f₁/f₀ с C_FA(1−π)/(C_FR π). При π=0,1 и цене ложного допуска в 20 раз выше ложного отказа граница отношения правдоподобия равна 180. Это не число на шкале косинуса; перевод требует калибровки.

**36. Как оценить точность, если один человек дал тысячу похожих кадров?** При целевой метрике «средний человек» сначала считаем долю правильных решений aᵢ внутри личности, затем усредняем по личностям. Для двух людей с результатами 990/1000 и 0/1 получится (0,99+0)/2=49,5%, тогда как покадровое значение 990/1001≈98,9%. Оба числа отвечают на разные вопросы; выборку для переноса на новых людей разделяют по личности.

## 37–42. Стабильность видеотреков

**37. При каком дрейфе можно переиспользовать прежнего победителя?** Для единичного шаблона |(q′−q)·x|≤‖q′−q‖=δ. Старый победитель с отрывом g остаётся единственным при g>2δ. Порог допуска также сохраняется, если старая оценка минус δ остаётся выше порога. Гарантия требует верхней границы дрейфа эмбеддинга; IoU рамок сам её не доказывает.

**38. Как из скорости дрейфа получить максимальный срок кэша?** Если доказано δ≤v h за h кадров, то сохраняем ранжирование при h<g/(2v). Для g=0,12 и v=0,01 максимальное целое h=5: на шестом кадре возможна ничья. При смене личности предположение о скорости нарушено, поэтому гарантия заканчивается.

**39. Как распределить бюджет обновления между треками?** Пусть цена устаревания в кадре возраста a равна cᵢa, период обновления Tᵢ, частота fᵢ=1/Tᵢ. При равномерных фазах средняя цена cᵢ(Tᵢ−1)/2. Минимизируем Σcᵢ/(2fᵢ) при Σfᵢ=B. Получаем fᵢ=B√cᵢ/Σ√cⱼ до ограничений частоты. При ценах 9 и 1 доли бюджета 3/4 и 1/4; целые периоды требуют отдельного расписания.

**40. Как совместить предсказанную и измеренную координату лица?** Для независимых несмещённых ошибок с дисперсиями P и R минимум средней квадратичной ошибки даёт K=P/(P+R), x′=x+K(z−x), P′=PR/(P+R). При x=100, z=110, P=9, R=16 имеем K=0,36, x′=103,6 и P′=5,76.

**41. Почему ближайшая пара не всегда правильно распределяет лица по трекам?** При матрице затрат [[1,2],[2,100]] жадный выбор минимума 1 оставляет стоимость 100, итого 101. Перестановка даёт 2+2=4. Для n треков минимизируем сумму по взаимно однозначным назначениям; задача решается венгерским алгоритмом за O(n³). Фиктивные назначения нужны, если допустим пропуск.

**42. Во сколько раз три подтверждения снижают ложные допуски?** При независимых кадрах риск p³. Если с вероятностью r возникает общая причина, которая даёт ложный допуск на всех трёх кадрах, а иначе кадры независимы с риском p, получаем r+(1−r)p³. При r=0,001, p=0,01 это 0,001000999. Куб покадрового риска нельзя подставлять без проверки зависимости.

## 43–48. Очереди, ресурсы и задержка

**43. Сколько запросов успеют начать вычисление до дедлайна?** При одновременном поступлении, c свободных работниках и постоянном времени s старты происходят в 0,s,2s,… Строгий старт до D>0 даёт не более c·ceil(D/s) запросов. При двух работниках, 50 мс и бюджете 250 мс — 10 стартов. Включение равенства на границе изменило бы ответ.

**44. Что меняет очередь между декодированием и моделью?** При отдельных ресурсах с временами d и m для N одинаковых кадров двухступенчатый конвейер занимает d+m+(N−1)max(d,m). При d=8, m=40, N=10 получаем 408 мс вместо 480 последовательных. Если стадии конкурируют за одно ядро, предположение о параллельных ресурсах надо проверить замером.

**45. Как оценить предел потока запросов при смеси кадров?** Для одного последовательного работника условие нагрузки λE[S]<1. При 80% запросов по 20 мс и 20% по 100 мс E[S]=36 мс. Для двух равномерно загруженных работников необходима λ<55,56 запросов/с. Из этого не следует гарантия p95; пики могут давать очередь и ниже предела.

**46. Как разбить четыре работника между двумя независимыми стадиями?** Для k работников декодирования по 20 кадров/с и 4−k работников модели по 12 кадров/с поток равен min(20k,12(4−k)). Перебор k=1,2,3 даёт 20,24,12. Оптимум — 2+2, хотя декодирование само по себе быстрее.

**47. Какие кадры сохранить, если завершить все к срокам невозможно?** Для независимых задач на одном работнике, готовых в момент 0, с одинаковой ценностью, сортируем по дедлайну. При превышении очередного дедлайна удаляем самую длинную из принятых задач: это освобождает максимум времени при потере ровно одной задачи. Для длительностей (4,2,2) и сроков (4,4,5) останутся две короткие, обе завершатся вовремя. При разных ценностях эта стратегия уже не гарантирует оптимум.

**48. Когда пакетная обработка проигрывает одиночной по задержке?** При заполнении пакета b пуассоновским потоком λ средний запрос ожидает (b−1)/(2λ) до заполнения, если таймера нет и работник свободен. При b=8 и λ=40/с это 87,5 мс ещё до инференса. Даже мгновенная модель не выполнит средний бюджет 50 мс в этой политике. Нужен меньший пакет или таймер.

## 49–54. Как доказать, что изменение полезно

**49. Каков потолок ускорения всего запроса при ускорении одного ядра?** По Амдалу T′/T=(1−p)+p/s. Если участок занимает 30% и ускорен в 4 раза, T′/T=0,775, ускорение всего запроса 1,29×. Даже бесконечно быстрый участок дал бы лишь 1,43×.

**50. Реален ли выигрыш классификатора на одних и тех же парах?** Берём только несогласные случаи. Если новая версия исправила 12 ошибок и добавила 2, то при симметричной нулевой гипотезе двусторонний точный тест Макнемара даёт 2·(1+14+91)/2¹⁴≈0,01294. Решения должны быть парными, а пары — независимыми; серии кадров одного человека так считать нельзя.

**51. Сколько парных прогонов нужно для заданной точности времени?** Для независимых парных разностей с оценкой стандартного отклонения σ приближённая полуширина 95% интервала равна 1,96σ/√n. При σ=2 мс и цели 0,5 мс получаем n≥62. Это расчёт для планирования; окончательный интервал при неизвестной дисперсии использует t-критическое значение или подходящую повторную выборку.

**52. Сколько информации несут сто соседних видеокадров?** При стационарной корреляции ρᵏ дисперсия среднего равна σ²/n · [1+2Σₖ₌₁ⁿ⁻¹(1−k/n)ρᵏ]. Отсюда n_eff=n/[выражение в скобках]. При n=100, ρ=0,9 получаем около 5,81 независимого наблюдения. Подставлять 100 в формулу независимой стандартной ошибки слишком оптимистично.

**53. Скольких запросов достаточно хотя бы для наблюдения верхних 5% задержек?** Для независимых задержек из непрерывного распределения вероятность не увидеть ни одного значения выше истинного p95 равна 0,95ⁿ. Чтобы она была не выше 5%, нужно n≥59. Это гарантирует только шанс увидеть хвост, а не точно оценить его квантиль.

**54. Можно ли заявить «точность сохранилась», если на тесте нет ни одного расхождения?** Для n независимых репрезентативных пар старая/новая версия без расхождений дают одностороннюю верхнюю границу риска расхождения 1−0,05^(1/n). При n=15 это 18,10%, при n=3000 — 0,0998%. Побитовое равенство конкретных выходов установлено точно; перенос на популяцию требует обоснованной выборки. Совпадение версий одновременно не доказывает правильность их общего ответа.


## 55–64. Оптика и восстановление координат

**55. На каком расстоянии лицо перестаёт занимать 40 пикселей?** В модели камеры-обскуры ширина изображения лица d=fW/Z. При фокусном расстоянии f=1200 пикселей и фронтальной ширине W=0,16 м условие d≥40 даёт Z≤4,8 м. Реальную ширину и ракурс нужно учитывать при переносе этой границы на камеру.

**56. Каков предел выдержки при движении поперёк кадра?** При почти постоянной глубине длина смаза b=fvT/Z. Если f=1000 пикселей, v=1,5 м/с, Z=3 м и допустимы два пикселя смаза, T≤0,004 с. Это 1/250 секунды до учёта собственного движения камеры.

**57. Как косой ракурс меняет минимальный размер лица?** Для плоской площадки в слабой перспективе горизонтальная ширина d(θ)=d₀ cos θ. При 48 пикселях анфас граница 32 пикселя достигается при |θ|=arccos(2/3)≈48,19°. Это модель проекции площадки, а не предел распознавания человека.

**58. Сколько рамки сохранить после поворота кропа?** Охватывающая рамка прямоугольника w×h после поворота имеет ширину |w cos θ|+|h sin θ|, высоту |w sin θ|+|h cos θ|. Для 80×100 и 30° получаем 119,28×126,60 пикселя. При целочисленных границах округляем внешние координаты наружу.

**59. Как восстановить исходную координату с учётом полосы дополнения?** При фактическом масштабе s=rw/w и левом отступе p имеем x=(u−p)/s. Если w=1000, rw=700, p=2 и u=212, то x=300. Для y нужен собственный масштаб rh/h: округление размеров может сделать масштабы разными.

**60. Как ошибка в масштабе нарастает к краям кадра?** Если инвертировать масштаб s(1+ε) вместо s при точном отступе, то x′=x/(1+ε), |Δx|=|xε/(1+ε)|. При x=900 и завышении на 1% ошибка ≈8,91 пикселя. Поэтому смещение нельзя оценить по одной центральной точке.

**61. Как накапливаются ковариации двумерных ориентиров после аффинного отображения?** Для y=Ax+t с фиксированными A,t имеем Cov(y)=AΣAᵀ. Независимые дисперсии 4 и 1 после поворота на 90° меняются местами; дополнительное увеличение вдвое даёт дисперсии 4 и 16. Перенос сам дисперсию не меняет.

**62. Какая часть ошибок действительно согласуется с изотропной моделью ориентира?** Для независимых нормальных ошибок по x,y с σ=2 пикселя квадрат радиуса, делённый на 4, имеет распределение χ² с двумя степенями свободы. Радиус 95% равен σ√(−2 ln 0,05)=4,90 пикселя. Проверяется доля попаданий размеченных точек внутрь этого круга.

**63. Какую точку выбрать для переноса при редких больших выбросах?** При потере Σ|t−dᵢ| в одном измерении минимум достигается в медиане: слева и справа уравновешиваются знаки производных. Для смещений (1,2,2,3,80) ответ 2 вместо среднего 17,6. При сумме покоординатных L1-потерь применяем это по каждой оси отдельно.

**64. Сколько случайных пар нужно для надёжной гипотезы выравнивания?** Из пяти ориентиров три надёжны. Вероятность выбрать две надёжные без возвращения внутри попытки равна C(3,2)/C(5,2)=0,3. Для независимых попыток с повторением пар нужно ceil(ln 0,01/ln 0,7)=13 попыток на вероятность успеха ≥99%. Здесь всего 10 разных пар, поэтому полный перебор дешевле и гарантирует присутствие надёжной пары, но ещё требует правила выбора гипотезы.

## 65–74. Детекция и объединение рамок

**65. Как перевести порог YuNet в порог произведения двух голов?** Для s=√(co), c,o∈[0,1] условие s≥t равносильно co≥t². При t=0,7 и c=0,8 нужно o≥0,6125. При переносе в код следует отдельно проверить округление ровно на пороге.

**66. Можно ли исключить позицию до чтения второй уверенности?** Из o≤1 следует s≤√c. При c<t² позицию можно исключить независимо от o. Если t=0,75, то c=0,55 гарантированно не проходит, поскольку 0,55<0,5625. При c=t² и o=1 включающий порог проходит.

**67. Как горизонтальный и вертикальный сдвиги вместе влияют на IoU?** Для одинаковых рамок ширины w и высоты h I=(w−|dx|)₊(h−|dy|)₊. При 80×100 и сдвиге (8,10) I=6480, IoU=6480/(16000−6480)≈0,681. Устойчивости по одной оси недостаточно.

**68. При каком изменении размера концентрическая рамка потеряет совпадение?** Для одинаковых пропорций и линейного масштаба k≥1 меньшая рамка вложена в большую, IoU=1/k². При пороге 0,4 допускается увеличение до √2,5≈1,581 раза. Для уменьшения нижняя граница симметрична: k≥√0,4.

**69. Сколько теряем от округления координат небольшого лица?** Если каждую границу квадрата со стороной d сдвинуть внутрь на 0,5 пикселя, IoU=(d−1)²/d². Для d=8 это 0,7656, для d=80 — 0,9752. Хранение дробных координат до конца NMS особенно существенно для малых объектов.

**70. Сколько заведомо лишних клеток добавляет округление двух измерений?** Для целых размеров w,h и шага 32 добавки a,b лежат в [0,31]. Дополнительная площадь равна ah+bw+ab≤31(h+w)+961. У содержимого 832×468 добавляется только 832×12=9984 пикселя. Формула позволяет учитывать цену паддинга отдельно от площади лица.

**71. Может ли жадный NMS терять суммарную уверенность?** Возьмём единичные по высоте рамки [0,10], [4,14], [8,18], порог IoU 0,4 и оценки 0,8; 0,9; 0,8. Средняя пересекается с обеими с IoU=6/14, крайние — с 2/18. Жадный NMS оставит 0,9; допустимая пара крайних даёт 1,6. Следовательно NMS не решает задачу максимального веса независимого множества.

**72. Как усреднить две независимые оценки одной границы рамки?** При несмещённых ошибках с дисперсиями 4 и 9 обратные веса дают оценку (9x₁+4x₂)/13 и дисперсию 36/13. Для x₁=100,x₂=106 получаем 101,85. Применять слияние можно лишь после сопоставления двух детекций одному лицу.

**73. Какова доля ложных обнаружений при редких лицах?** При доле положительных позиций π, полноте r и вероятности ложного срабатывания f точность положительного ответа равна πr/[πr+(1−π)f]. Для π=0,01,r=0,9,f=0,01 результат 47,62%, ложных среди ответов 52,38%. Знаменатель включает истинные и ложные детекции.

**74. Когда второй детектор действительно добавляет полноту?** По включению–исключению R_union=R₁+R₂−P(оба нашли|лицо). Если R₁=0,85,R₂=0,80 и оба находят 0,72, объединение даёт 0,93. Его вклад поверх первого — восемь процентных пунктов; перемножение частот промаха потребовало бы условной независимости.

## 75–84. Вычислительные ядра и арифметика

**75. Сколько MAC экономит разложение обычной свёртки на depthwise и pointwise?** На выходную позицию обычная 3×3 при C=32,O=64 требует 9CO=18 432 MAC. Разложение требует 9C+CO=2336, или в 7,89 раза меньше. Равенство моделей требует соответствующей структуры весов или отдельного обучения.

**76. Каков размер эффективного рецептивного поля?** При ядре k, дилатации d и предшествующем шаге j прирост равен (k−1)dj. Две последовательные 3×3, первая с шагом 2, вторая с шагом 1, дают поле 3+2×2=7 и суммарный шаг 2. Один выход второй карты зависит от семи позиций исходной оси.

**77. Когда группировка каналов экономит параметры точно в g раз?** Для g равных групп при делимости C,O число весов ядра k×k равно k²CO/g. При k=3,C=64,O=96,g=8 получаем 6912 вместо 55 296. Число независимых смещений выхода при этом остаётся 96.

**78. Каков минимальный объём кольцевого буфера для потоковой свёртки?** Для вертикальной свёртки высоты k с дилатацией d полный интервал исходных строк — 1+(k−1)d. При k=3,d=2 нужны пять строк при обычном последовательном вводе, включая текущую. Для ширины 640, 16 каналов FP32 это 204 800 байт; промежуточную карту целиком хранить не требуется.

**79. При какой доле нулей разреженное хранение выгоднее плотного?** Если значение FP32 и индекс занимают по 4 байта, список без указателей строк стоит 8nnz байт против 4N. Нужно nnz/N<0,5. При наличии указателей строк их стоимость дополнительно вычитается из бюджета; одна только разреженность не гарантирует ускорения.

**80. Какой предел пропускной способности диктует чтение шаблонов?** Если один полный поиск читает 128 МиБ, а эффективная полоса памяти 32 ГиБ/с, одно чтение занимает не меньше 128/(32×1024)=3,906 мс. Допущение — холодная матрица, один полный проход. Подготовка запроса и выбор top-k добавят время.

**81. Как перенести скалярное смещение через линейное преобразование?** Для фиксированного вектора смещения m имеем W(x−m)+b=Wx+(b−Wm). Для W=(2,−1),m=(3,4),b=5 новое смещение равно 3. Слияние вычитания на входе допустимо и для разных смещений каналов; паддинг свёртки требует согласования на границах.

**82. Как ограничить ошибку полиномиальной аппроксимации экспоненты в малом интервале?** Остаток ряда до степени 5 ограничен exp(a)a⁶/720 при |x|≤a. Для a=ln2/2 верхняя граница ≈3,40×10⁻⁶. Это оценка усечения в точной арифметике; редукцию аргумента и округление коэффициентов проверяют дополнительно.

**83. Как смешение знака при округлении смещает квантователь?** Для X, равномерного на [0,Δ), округление вниз даёт ошибку Q−X со средним −Δ/2 и MSE Δ²/3. Округление к ближайшему даёт нулевое среднее и MSE Δ²/12. При этих условиях MSE уменьшается вчетверо; клиппинг и неравномерность распределения меняют результат.

**84. Почему прямая формула дисперсии теряет значащие цифры?** Для X=10⁵±0,01 с равными вероятностями Var(X)=10⁻⁴, но E[X²] и E[X]² порядка 10¹⁰. В FP32 шаг около 10¹⁰ равен 1024, поэтому их разность не разрешает 10⁻⁴. Центрирование до возведения в квадрат убирает это вычитание; ошибку первоначального хранения X оно не обращает.

## 85–94. Представления лиц и расстояния

**85. Насколько изменится направление после нормировки возмущённого вектора?** Для ненулевых x и x+e разложение разности нормированных векторов и обратное неравенство треугольника дают ‖normalize(x+e)−normalize(x)‖≤2‖e‖/‖x‖. При ‖x‖=2,‖e‖=0,01 граница 0,01. Нулевой вектор нужно обрабатывать отдельно.

**86. Какой линейный оператор сохраняет все косинусы?** Достаточно WᵀW=cI при c>0: числитель умножается на c, произведение норм — тоже. Например, поворот на 90° и масштаб 3 сохраняют все оценки. Неравномерное масштабирование (2,1) переводит косинус между (1,1) и (1,−1) из 0 в 3/5.

**87. Как правильно декоррелировать признаки при известной ковариации?** Если Σ=LLᵀ положительно определена, y=L⁻¹(x−μ) имеет единичную ковариацию. При диагонали (4,9) делим центрированные координаты на 2 и 3. Такой переход меняет метрику поиска и требует повторного подбора порога.

**88. Какой двумерный признак отбросить при сжатии PCA?** Для центрированных данных оптимальная по средней квадратичной ошибке ортопроекция ранга k оставляет k крупнейших собственных значений. При спектре (9,4,1) и k=2 ошибка реконструкции равна 1, сохранённая доля дисперсии 13/14≈92,86%. Такая доля не определяет точность идентификации.

**89. Можно ли гарантировать ошибку dot-product после ортопроекции через невязки?** Для ортопроектора P имеем x·y−Px·Py=((I−P)x)·((I−P)y). При нормах невязки 0,2 и 0,1 модуль ошибки ≤0,02 до нормировки проекций. Это даёт критерий повторного поиска в исходном пространстве.

**90. Как устранить систематическое смещение модели при сравнении двух сессий?** В аддитивной модели y=x+b+e, E[e]=0, оценка b по m парным якорям равна среднему yᵢ−xᵢ и минимизирует сумму квадратов невязок. При разностях 0,1; 0,3; 0,2 по координате получаем 0,2. Нелинейное изменение пространства такая поправка не описывает.

**91. Как оценить ортогональное соответствие двух пространств по якорям?** Для строк X,Y и задачи min‖XR−Y‖² при RᵀR=I максимизируем tr(RᵀXᵀY). Если XᵀY=UΣVᵀ, решение R=UVᵀ. Для X=I и ортогональной Y получаем R=Y и нулевую невязку; перенос на новые личности проверяется отдельно.

**92. Какой средний квадрат ошибки шаблона при добавлении одинаково точных независимых видов?** Для среднего n наблюдений одной точки с шумом ковариации Σ математическое ожидание квадрата нормы ошибки равно tr(Σ)/n. При tr(Σ)=0,12 и n=6 это 0,02 до нормировки. Систематический сдвиг b добавляет ‖b‖² независимо от n.

**93. Как объединить два накопленных шаблона без исходных векторов?** Нужно хранить суммарные веса и ненормированные векторные суммы r₁,r₂. Итоговое направление normalize(r₁+r₂). Если r₁=(9,0),r₂=(0,1), угол ≈6,34°, тогда как усреднение двух уже нормированных направлений даёт 45°. Одних направлений недостаточно для точного объединения.

**94. Насколько различаются арифметическое и сферическое середины двух направлений?** Для единичных неантиподальных x,y с одинаковыми весами normalize(x+y) находится на угловой биссектрисе, поскольку скалярные произведения с x и y равны. При угле 120° получаем по 60° до каждого вида. Для антиподов сумма нулевая и единственной середины нет.

## 95–104. Точный и приближённый поиск

**95. Достаточно ли top-k из каждой части распределённой галереи?** Да, при едином полном порядке «оценка, затем глобальный ID». Если запись не в локальном top-k, в той же части уже есть k записей лучше. Из восьми частей для глобального top-5 достаточно получить не более 40 записей. Локальные несопоставимые ID нарушили бы детерминированность равенств.

**96. Сколько памяти нужно потоковому top-k?** Поддерживаем min-heap из k лучших по полному порядку. После обработки строки заменяем корень лишь при улучшении; индукцией куча содержит top-k просмотренного префикса. Для миллиона строк и k=5 храним пять пар «ID, оценка» дополнительно к входному блоку, время O(N log k).

**97. Когда можно не перечитывать галерею после удаления одного шаблона?** Если храним точный упорядоченный top-(k+1) и удалена одна запись, удаляем её из списка и берём первые k. Удаление ниже списка тоже ничего не меняет. Для k=5 нужен шестой сосед; при двух одновременных удалениях для такой же гарантии нужны семь.

**98. Как обновить top-k при вставке новых шаблонов?** Top-k объединения старой галереи и вставки равен top-k объединения старого top-k и всех новых записей по №95. Для уже рассчитанного фиксированного запроса при N=65 536 и 20 вставках нужно только 20 новых dot-product. Правило неприменимо, если изменились запрос или старые шаблоны.

**99. Как оценить минимальное расстояние до осевого блока признаков?** Для прямоугольника [lᵢ,uᵢ] квадрат нижней границы равен Σmax(lᵢ−qᵢ,0,qᵢ−uᵢ)²: это расстояние до покоординатно зажатой проекции. Для q=(3,−1), блока [0,2]×[0,2] получаем 2. Блок можно пропустить при текущем квадрате радиуса строго меньше 2.

**100. Как оценить кандидата по расстоянию до одного опорного шаблона?** В евклидовой метрике d(q,x)≥|d(q,p)−d(x,p)|. Если эти расстояния 0,2 и 1,1, нижняя граница 0,9. При нужном радиусе 0,8 точный dot не нужен. Для нескольких опор берём максимум границ; складывать их нельзя.

**101. Какой выигрыш даёт порядок блоков при ранней остановке?** На шаге с порогом расстояния R проверяем блоки по возрастанию их нижней границы L. Как только очередное L>R, все последующие отпадают. При L=(0,1; 0,4; 0,7; 0,9) и найденном после второго блока R=0,5 два последних пропускаются. При точном равенстве учитываем tie-break.

**102. Как выбрать порог для двухступенчатого поиска по стоимости?** При цене грубой оценки a на строку, точного пересчёта b и доле финалистов f средняя цена a+fb. Выигрыш над прямым пересчётом при f<1−a/b. При a=3,b=10 финалистов должно быть меньше 70%; построение и чтение индекса учитываем отдельно. Именно поэтому формально безопасное отсечение иногда замедляет поиск.

**103. Как перевести угловое расстояние в вероятность коллизии случайного гиперплоскостного хеша?** Для изотропной гиперплоскости через начало вероятность одинакового знака равна 1−θ/π: разные знаки занимают угловую долю θ/π. При θ=60° это 2/3. Для восьми независимых битов вероятность полного совпадения (2/3)⁸≈3,90%. Это вероятностный кандидатный поиск, а не точный.

**104. Сколько независимых хеш-таблиц нужно для заданной вероятности попадания?** Если одна таблица находит конкретного соседа с вероятностью p, то L независимых находят его с вероятностью 1−(1−p)ᴸ. При p=0,2 для ≥95% нужно L≥14. Корреляция таблиц уменьшает ожидаемый выигрыш; это гарантия модели случайности, а не полноты реальной базы.

## 105–114. Биометрическая статистика и калибровка

**105. Сколько ложных идентификаций ожидать от смешанного потока?** При Q запросах, доле незарегистрированных u и вероятности ложной идентификации на такой запрос f ожидается Quf. Для 50 000 запросов, u=0,12 и f=0,002 получаем 12 случаев. Ошибочный выбор другого зарегистрированного человека нужно учитывать отдельным слагаемым.

**106. Как разложить ошибку идентификации зарегистрированного?** События «выдан правильный ID», «выдан другой ID» и «отказ» несовместны и исчерпывают ответы. Для счётчиков 940,15,45 на 1000 запросов FNIR=(15+45)/1000=6%, ошибочная выдача — 1,5%, отказ — 4,5%. Одинаковый FNIR может скрывать разную цену ошибок.

**107. Насколько может измениться FPIR при ограниченном сдвиге состава посетителей?** Если частоты групп изменились с w на v, а внутри групп риски pᵢ стабильны, то |Σ(vᵢ−wᵢ)pᵢ|≤TV(v,w)(max pᵢ−min pᵢ). Доказательство: положительная и отрицательная массы изменения обе равны TV. При TV=0,10 и диапазоне рисков от 1% до 5% сдвиг не превышает 0,4 процентного пункта.

**108. Какая точность среди выданных ID при наличии ошибочных выдач зарегистрированным?** Пусть 80% запросов от зарегистрированных, для них 95% правильных и 1% неправильных выдач; для остальных FPIR=2%. Тогда доля правильных среди выданных равна 0,8×0,95/[0,8×0,96+0,2×0,02]≈98,45%. Отказы из знаменателя исключены.

**109. Что произойдёт с калиброванной вероятностью при изменении априорных шансов?** При неизменном отношении правдоподобий новые posterior odds равны старым, умноженным на отношение новых prior odds к старым. При старой априорной доле 0,5, новой 0,1 и старой posterior 0,9 новые шансы равны 9×(1/9)=1, новая вероятность 0,5. Сдвиг условных распределений этой формулой не исправляется.

**110. Как подобрать решение при наличии ручной проверки?** Если posterior своего равна p, потери автоматического допуска C_FA(1−p), отказа C_FR p, идеальной ручной проверки C_R. Берём минимум. При C_FA=10,C_FR=2,C_R=0,5 ручная проверка оптимальна для 0,25<p<0,95. На границах решения равноценны.

**111. Как оценить разницу ошибок одной системы на двух камерах разного объёма?** Для независимых запросов оценка стандартной ошибки разности долей равна √[p₁(1−p₁)/n₁+p₂(1−p₂)/n₂]. При 10/1000 и 30/1000 разность 0,02 и SE≈0,006245. Если обе камеры наблюдают одних посетителей, нужен парный или кластерный расчёт.

**112. Как получить глобальную частоту из стратифицированного теста?** При целевых весах страт wᵢ получаем p=Σwᵢpᵢ. Если ночные и дневные ошибки 4% и 1%, а ночная доля в эксплуатации 20%, итог 1,6%. Простое среднее двух равных тестовых подвыборок дало бы 2,5%.

**113. Как распределить разметку по камерам при одинаковой цене примера?** При независимой стратифицированной оценке минимизация Σwᵢ²σᵢ²/nᵢ при сумме n даёт nᵢ∝wᵢσᵢ. Для w=(0,75;0,25), σ=(0,1;0,3) доли бюджета равны: по 500 из 1000. Дисперсии берутся из пилота и переоцениваются при дрейфе.

**114. Как меняется риск после повторных независимых попыток прохода?** При вероятности ложного допуска p на попытку и полном сбросе состояния вероятность хотя бы одного допуска за m попыток равна 1−(1−p)ᵐ. Для p=0,001 и m=5 это 0,499%. При зависимости верхняя граница по сумме вероятностей — 0,5%; реальную политику повторов проверяют сессиями.

## 115–124. Время, движение и трекинг

**115. Какую ошибку даёт экстраполяция с постоянной скоростью?** Если ускорение ограничено |a|≤A и начальные координата и скорость точны, то |x(t)−x₀−v₀t|≤At²/2 интегрированием дважды. При A=200 пикселей/с² и пропуске 0,2 с получаем до 4 пикселей.

**116. Как шум координат портит оценку скорости?** Для двух независимых измерений с дисперсией σ² оценка v=(x₂−x₁)/Δt имеет дисперсию 2σ²/Δt². При σ=2 пикселя и Δt=0,1 с стандартное отклонение скорости 28,28 пикселя/с. Слишком короткая база делает оценку шумной.

**117. Как уменьшить ошибку скорости по нескольким кадрам?** В модели xᵢ=a+vtᵢ+eᵢ МНК даёт v̂=Σ(tᵢ−t̄)xᵢ/Σ(tᵢ−t̄)² и Var(v̂)=σ²/Σ(tᵢ−t̄)² при независимом шуме. Для t=(0,1,2,3) знаменатель 5; при σ²=4 дисперсия 0,8.

**118. Как подобрать экспоненциальное сглаживание при переменном FPS?** Чтобы сохранить постоянную времени τ, берём α(Δt)=1−exp(−Δt/τ). При τ=0,2 с и Δt=0,04 с α≈0,1813. Два шага по 20 мс для постоянного входа дают тот же вес истории, что один шаг 40 мс.

**119. Когда новый вектор движения статистически несовместим с прогнозом?** Для нормальной инновации e с известной ковариацией S вычисляем eᵀS⁻¹e. При S=diag(4,9), e=(4,3) значение 5. В двух измерениях вероятность большей величины exp(−5/2)≈8,21%; 95%-й эллипс такую точку включает.

**120. Как часто может пропасть человек между двумя проверками?** При модели постоянной интенсивности выхода λ вероятность сохранения трека до t равна exp(−λt). При λ=0,2/с требование вероятности сохранения ≥0,99 даёт t≤−ln(0,99)/0,2≈50,25 мс. На реальном потоке интенсивность зависит от сцены.

**121. Как оценить потерю от пропуска каждого второго кадра при коротком событии?** При равномерной фазе начала события длительностью L и периодических мгновенных выборках периода T вероятность увидеть событие min(1,L/T). Для L=30 мс и T=80 мс получаем 37,5%. При синхронной фазе эта вероятностная модель неприменима.

**122. Как определить момент максимального сближения двух треков между кадрами?** При относительном положении r и постоянной относительной скорости v минимизируем ‖r+tv‖² на [0,T]. Для v≠0 ответ t*=clip(−r·v/‖v‖²,0,T); при v=0 расстояние постоянно. Для r=(10,2), v=(−5,0), T=3 пик сближения через 2 с, расстояние 2 пикселя. Проверка одних концов интервала пропустила бы сближение.

**123. При каком разрыве времени идентификатор трека нельзя переиспользовать по геометрии?** При точных координатах и предельной скорости V новая точка на расстоянии d достижима только при d≤VΔt. При d=45 пикселей, Δt=0,1 с и V=300 пикселей/с достижимы лишь 30. С радиальной погрешностью до e у каждого конца безопасный порог исключения d>VΔt+2e.

**124. Какова выгода повторного эмбеддинга после смены освещения?** Пусть цена нового вычисления C, цена ошибки L, вероятность ошибки кэша p₀, свежего решения p₁. По ожидаемой потере пересчёт выгоден, когда L(p₀−p₁)>C. При L=100, p₀=0,06,p₁=0,02,C=3 выигрыш одной единицы. Эти вероятности должны оцениваться на сопоставимых эпизодах.

## 125–134. Пропускная способность сервиса

**125. Сколько запросов одновременно находится в системе в среднем?** Для стационарного потока завершённых запросов закон Литтла даёт L=λW. При 40 запросах/с и среднем времени пребывания 0,2 с среднее число в системе 8. Это среднее по одним и тем же границам учёта, не p95.

**126. Как загрузка влияет на задержку в простейшей очереди?** Для M/M/1, λ<μ, среднее полное время 1/(μ−λ). При μ=50/с рост входа с 30 до 45/с меняет его с 50 до 200 мс. Числа применимы при пуассоновских приходах и экспоненциальном времени обслуживания.

**127. Почему одинаковое среднее время модели даёт разные очереди?** Для M/G/1 с FCFS среднее ожидание λE[S²]/[2(1−ρ)]. При λ=20/с и среднем S=0,02 с, ρ=0,4. Постоянное время даёт 6,67 мс ожидания; экспоненциальное с тем же средним удваивает второй момент и даёт 13,33 мс.

**128. Как оценить очередь после короткого всплеска?** В жидкостной модели рост равен (λ−μ)T при λ>μ. Если 2 секунды приходят 80 запросов/с при мощности 50, накопится 60. После падения входа до 20/с очередь опустеет за 60/(50−20)=2 с при неизменной мощности.

**129. Сколько избыточных повторов создаёт перегрузка?** При независимом отказе с вероятностью p и не более m попытках среднее число попыток Σⱼ₌₀ᵐ⁻¹pʲ. При p=0,5,m=3 получается 1,75 попытки на исходный запрос, а вероятность окончательного отказа 0,125. Под перегрузкой p обычно меняется с новым потоком.

**130. Когда выгодно передавать компактный вектор?** Пусть кодирование добавляет 0,3 мс, экономит 8000 байт, полоса R байт/с. Выигрыш при 8000/R>0,0003, то есть R<26,67 МБ/с без накладных расходов. В общем сравнении учитывают также время декодирования и фактическое сжатие HTTP.

**131. Когда предварительная загрузка весов окупает запуск?** Если прогрев занял дополнительные C=0,8 с, а на каждом запросе экономится 2 мс, точка равенства N=C/0,002=400 запросов. Для N>400 суммарное время меньше. Если предзагрузка экономит только память, временного выигрыша из этой модели не следует.

**132. Какой предел одновременно декодированных 4K-кадров даёт память?** Для RGB8 размер 3840×2160×3=24 883 200 байт. При бюджете 256 МиБ на одни пиксели верхняя граница floor(268 435 456/24 883 200)=10 кадров. Буферы декодера и модель уменьшают рабочий лимит.

**133. Как найти лучший размер пакета при фиксированных приходах?** Для перебора b с задержкой вычисления T(b) и накопления (b−1)/(2λ) берём минимум суммы среди b, удовлетворяющих b/T(b)≥λ. При λ=50/с, b=(1,2,4), T=(22,28,40) мс одиночный режим неустойчив, полная модельная задержка для остальных 38 и 70 мс. Побеждает пакет 2 в приближении без дополнительной очереди.

**134. Как растёт хвост задержек при параллельном поиске по частям галереи?** При параллельном обращении к четырём независимым одинаковым частям время ответа есть максимум, F_max(t)=F(t)⁴. Если каждая часть укладывается в t с вероятностью 0,95, все вместе укладываются лишь с вероятностью 0,8145. Для общего p95 каждая должна иметь F(t)≥0,95^(1/4)≈0,9873. При последовательном обходе задержки складываются.

## 135–144. Эксперименты и статистическая достоверность

**135. Как оценить среднее ускорение на разных устройствах?** Для симметричного усреднения отношений используют геометрическое среднее. При ускорениях 2× и 0,5× оно равно 1×; арифметическое 1,25× нарушает симметрию при обмене версий. Для фактической нагрузки используют отношение взвешенных суммарных времён.

**136. Как из времён разных разрешений получить выигрыш на реальном потоке?** При 90% кадров 1080p и 10% 4K, временах до (70,160) мс и после (68,148) мс, средние равны 79 и 76 мс. Выигрыш времени 3/79≈3,80%. Усреднение процентов по двум строкам с равными весами дало бы другое число.

**137. Сколько ложных находок ждать при проверке 100 бесполезных вариантов?** При уровне 0,05 математическое ожидание числа ложноположительных результатов 5, независимо от зависимости тестов, если каждый тест корректен. Чтобы верхняя граница вероятности хотя бы одной ложной находки была 0,05, поправка Бонферрони задаёт 0,0005 на сравнение.

**138. Как агрегация может перевернуть сравнение версий?** Версия A быстрее B на простых кадрах (10 против 12 мс) и сложных (90 против 100). Если A получила 90% сложных, а B только 10%, наблюдаемые средние 82 против 20,8 мс. При одинаковой смеси 50/50 получаем 50 против 56 мс. Для вывода используем одинаковые входы или стратификацию.

**139. Как выбрать число прогревов при экспоненциальном переходном процессе?** Если добавка ко времени после k прогонов равна Aρᵏ, 0<ρ<1, нужно k≥ceil[ln(ε/A)/ln ρ]. При A=16 мс, ρ=0,5 и ε=0,5 мс достаточно пяти. При троттлинге закон может смениться, поэтому предпосылку проверяют трассой.

**140. Как оценить неопределённость времени, если часы имеют квант δ?** При округлении каждой из двух отметок к ближайшему абсолютная ошибка длительности ≤δ. Для суммарного замера n операций ошибка среднего ≤δ/n. При δ=1 мс и n=200 это 5 мкс на операцию, до учёта прочих источников шума.

**141. Как сравнить два запуска без предположения нормальности длительностей?** Для независимых пар без равенств при нулевой гипотезе симметрии знаков число побед имеет Bin(n,0,5). Девять побед из десяти дают двустороннее p=2(1+10)/1024≈0,02148. Тест использует направление изменений, теряя информацию об их размере.

**142. Какое улучшение реально нужно для экономии одного сервера?** При потоке λ, мощности работника μ и целевой загрузке r требуется ceil(λ/(rμ)) серверов. При λ=100/с,r=0,8,μ=40/с нужны четыре. Чтобы хватило трёх, μ≥100/(3×0,8)=41,67/с, то есть прирост минимум 4,17% от исходной мощности.

**143. Как отличить p95 успешных ответов от p95 всей службы?** Пусть 96 из 100 запросов быстро отвергнуты за 5 мс и четыре успешны за 500 мс. По правилу ближайшего ранга общий p95=5 мс, p95 успешных=500 мс, доля успеха=4%. Поэтому коэффициент успеха публикуют рядом с обеими задержками.

**144. С какой вероятностью случайная проверка найдёт ошибку в конечной партии кадров?** Если ровно K из N записанных кадров содержат дефект, при выборе n различных кадров риск пропустить все равен C(N−K,n)/C(N,n). Из 20 кадров с двумя плохими проверка пяти найдёт дефект с вероятностью 1−C(18,5)/C(20,5)≈44,74%. Это выборка без возвращения; независимые испытания здесь дали бы другое число.

## 145–154. Сквозная оптимизация и решения при ограничениях

**145. Как перемножать качество стадий без предположения независимости?** Если правильная идентификация возможна только после детекции, P(успех)=P(детекция)P(верный ID|детекция). При 0,9 и 0,96 итог 0,864. Во втором множителе нужен условный результат именно на обнаруженных лицах.

**146. В какую стадию вложить одинаковый бюджет улучшения?** При общей успешности DR предельные приросты равны R·ΔD и D·ΔR, когда другая условная вероятность фиксирована. Для D=0,8,R=0,95, ΔD=0,02 даёт +0,019, а ΔR=0,02 — +0,016. Если новая детекция находит более трудные лица, R измеряют заново.

**147. Как выбрать рабочий режим при бюджете ошибок?** Есть три измеренных точки (время мс, доля ошибок): A=(10;0,05), B=(14;0,02), C=(18;0,03). C доминируется B. При пределе ошибок 0,025 минимальное время среди допустимых — 14 мс. Это сравнение корректно лишь на одной выборке и при совместимых пределах неопределённости.

**148. Какая смесь двух режимов экономит время при ограничении средней ошибки?** Для лёгкого режима (10 мс;5%) и тяжёлого (30 мс;1%) случайная доля тяжёлого x даёт ошибку 0,05−0,04x. Для бюджета 2% нужно x≥0,75, минимальное среднее время 25 мс. Для адаптивного выбора по качеству нужны условные частоты ошибок.

**149. Когда ранний выход каскада оправдан по математическому ожиданию?** Быстрый этап стоит 4 мс, дорогой ещё 20 мс и вызывается с вероятностью q. Условие среднего времени ≤12 мс даёт 4+20q≤12, то есть q≤0,4. Чтобы режим принять, дополнительно проверяют точность на запросах, остановленных рано.

**150. Какую долю повторных кадров нужно распознать из кэша для безубыточности?** Если проверка кэша стоит h, а промах добавляет обычные C, ожидаемое время h+(1−p)C. При h=0,3 мс и C=3 мс нужен hit rate p>10%. Если сохранённое решение устарело, одного временного выигрыша недостаточно.

**151. Как посчитать общий выход при ошибках условной маршрутизации?** Из 1000 запросов 700 отправили в лёгкую ветвь с 14 ошибками, 300 в тяжёлую с 15. Общая ошибка (14+15)/1000=2,9%, хотя невзвешенное среднее двух ошибок (2%+5%)/2=3,5%. Состав потока и правило выбора ветви входят в определение метрики.

**152. Когда выгодно передавать кроп вместо полного кадра?** Для K областей по A пикселей, одинаковой глубины представления и доплаты H байт на область выгодно K(Ab+H)<Fb, где F — площадь кадра и b байт/пиксель. При F=1920×1080, A=112²,b=3,H=100 и K=32 это 1 207 424 против 6 220 800 байт до компрессии. Удалённая сторона при этом теряет контекст исходной детекции.

**153. Как выбрать число реплик для ограничения риска полной недоступности?** При независимых отказах реплики с вероятностью p одновременно недоступны с вероятностью pʳ. При p=0,02 и цели ≤10⁻⁴ нужны три реплики: две дают 4×10⁻⁴, три — 8×10⁻⁶. Общий сбой хранилища или питания нарушает модель независимости.

**154. Как выбрать следующее улучшение на основании текущего узкого места?** Для последовательных участков с временами tᵢ и доступным ускорением sᵢ экономия Δᵢ=tᵢ(1−1/sᵢ). Если поиск занимает 12 мс и его можно ускорить вдвое, а подготовка занимает 40 мс и её можно ускорить на коэффициент 1,2, экономия составит 6 и 6,67 мс. При равной инженерной цене и одинаковой точности выгоднее подготовка. После изменения повторяют полный замер, поскольку доли участков изменятся.

## Что применено и как воспроизвести

Для №34, 36, 105–107 добавлена оценка идентификации 1:N на фиксированных порогах. На один запрос приходится одно решение. Скрипт считает FPIR среди незарегистрированных, FNIR среди зарегистрированных, ошибочные выдачи и отказы по отдельности, а также макросредние по личностям. Датасет NPZ содержит матрицы enrollment и probes (512 компонент на строку) и соответствующие одномерные массивы enrolled_ids и probe_ids. Один шаблон на зарегистрированную личность. Для незарегистрированных нужны собственные устойчивые идентификаторы, чтобы макросреднее имело смысл. Пороги выбирают отдельно от оценочной выборки. Пример запуска с условными порогами:

```sh
PYTHONPATH=python python training/scripts/eval_open_gallery.py holdout.npz --min-score 0.50 --min-margin 0.05
python tests/verify_154_math_examples.py
PYTHONPATH=python OPENBLAS_NUM_THREADS=1 python tests/bench_gallery_prefix.py
```

Для №27 сравнили префиксную границу Коши с обычным Gallery на 32 768 синтетических шаблонах размерности 512, одном CPU и 16 запросах. Начальная нижняя граница top-5 получена как пятая по величине из нижних оценок всех строк. При префиксах 128, 256 и 384 медиана числа финалистов была 32 768, при 480 — 8933,5. Построение индекса вынесено за пределы замера; стоимость памяти и подготовки могла бы только ухудшить результат этого прототипа. Измерение относится к этой реализации и распределению данных.
