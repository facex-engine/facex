# Сравнение решений FaceX по визитам

Команда Go сопоставляет результаты двух фиксированных правил с независимой разметкой по ключу visit_id. Для каждого визита в каждом файле нужна ровно одна итоговая запись. Порядок строк произвольный. Дубликат, отсутствующий визит, лишний визит или неизвестное обозначение завершают запуск с ошибкой. При отсутствии детекции выгрузите фактическое решение приложения, например reject. Если результат утерян, сначала восстановите его по журналу.

Пример трёх входных CSV:

**roster.csv**
```csv
visit_id,expected_id
v1,42
v2,unknown
```

**before.csv**
```csv
visit_id,decision
v1,42
v2,42
```

**after.csv**
```csv
visit_id,decision
v2,review
v1,42
```

В разметке unknown означает человека вне зарегистрированной галереи. Зарегистрированные ID — неотрицательные целые числа int64. В решениях review означает передачу оператору, reject — автоматический отказ. Обе политики должны видеть одни и те же входные визиты и использовать согласованные ID и состав галереи. Для нескольких кадров сначала сведите решения по тому же правилу, которое применяет сервис за целый визит.

Запуск из go/facex:

```sh
go run ./cmd/visitcompare -roster roster.csv -before before.csv -after after.csv
```

В примере wrong_removed=1, wrong_introduced=0 и correct_id_to_review=0. Отчёт выдаёт раздельные итоги для зарегистрированных и неизвестных, а также таблицу переходов между исходами. В частности, переход wrong_known_id → correct_id означает исправление личности, а unknown_granted → unknown_reviewed означает передачу случая оператору. Ни один из этих счётчиков не предсказывает окончательное решение оператора.

При заранее выбранных правилах и независимых размеченных визитах можно добавить `-independent`. В JSON появятся p-значение парного теста и консервативный 95%-ный интервал для абсолютного снижения доли ошибочных автоматических выдач ID (доли от 0 до 1 по шкале частоты, отрицательная разность означает ухудшение). Для коррелированных повторных кадров или примеров, на которых настраивали правило, используйте описательный режим по умолчанию.
