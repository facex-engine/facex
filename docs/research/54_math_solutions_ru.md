# FaceX. 54 математические задачи с решениями

Здесь номер означает математическую постановку, а не коммит, тест или обещание ускорения. Примеры с заданными числами иллюстрируют формулы. Реальные FAR, задержки и распределения ошибок камер должны измеряться отдельно. Для распознавания обозначаем через q единичный вектор запроса, через x — единичный шаблон, через s=q·x — косинусную оценку. FAR — вероятность ложного допуска при заданном протоколе.

## 1–6. Как правильно выровнять лицо по ориентирам

**1. Найти поворот, масштаб и перенос при неодинаковой точности точек.** Минимизируем сумму wᵢ|yᵢ−czᵢ−t|², представив точки комплексными числами. Производная по t даёт t=ȳ−c z̄. После центрирования нормальное уравнение даёт c=Σwᵢ conj(zᵢ−z̄)(yᵢ−ȳ)/Σwᵢ|zᵢ−z̄|². Масштаб равен |c|, угол — arg(c). Средние взвешенные; сумма весов и знаменатель должны быть положительными. При одинаковых весах получаем преобразование из src/align.c. Для пяти точек с разной дисперсией ошибки наблюдения в y выбор wᵢ=1/σᵢ² соответствует взвешенному МНК.

**2. Когда оценка поворота и масштаба плохо обусловлена?** Обозначим S=Σwᵢ|zᵢ−z̄|². При фиксированных исходных точках и ошибках целевых точек eᵢ числитель изменения c равен Σwᵢ conj(zᵢ−z̄)eᵢ. По Коши–Буняковскому |Δc|≤√(Σwᵢ|eᵢ|²/S). Если S уменьшилось в 16 раз при том же бюджете шума, граница ошибки выросла в четыре раза. Одного числа успешно найденных ориентиров недостаточно для оценки устойчивости.

**3. Как проверить выпадение каждого ориентира без пяти новых полных подгонок?** Накопить W=Σw, Z=Σwz, Y=Σwy, U=Σw|z|², V=Σw conj(z)y. Тогда S=U−|Z|²/W и c=(V−conj(Z)Y/W)/S. Вычитание пяти слагаемых одной точки даёт решение без этой точки за O(1); все варианты — за O(n). При больших абсолютных координатах сначала переносим начало вблизи лица, иначе разность в S теряет точность.

**4. Насколько ошибка прямого преобразования сдвигает выборку пикселей?** При y=cz+t, возмущениях δc,δt и |δc|<|c| обратное отображение даёт |z′−z|≤(|δt|+|z||δc|)/(|c|−|δc|). Это следует непосредственно из z′−z=−(δt+zδc)/(c+δc). При |z|≤50, масштабе 1, |δc|≤0,01 и |δt|≤0,5 пикселя сдвиг не превосходит 1,011 пикселя.

**5. Какую пару точек брать при аварийном выравнивании по двум ориентирам?** Если ошибки в двух целевых точках независимы и имеют одинаковую дисперсию, c=(y₂−y₁)/(z₂−z₁), а дисперсия оценки пропорциональна 2σ²/|z₂−z₁|². Выбираем самую удалённую достоверную пару. Удвоение расстояния уменьшает дисперсию вчетверо. Для разного качества надо максимизировать |z₂−z₁|²/(σ₁²+σ₂²).

**6. Сколько яркости теряется при субпиксельной ошибке?** Внутри билинейной ячейки производная по x — выпуклая комбинация двух горизонтальных разностей, аналогично для y. Поэтому |ΔI|≤Gₓ|Δx|+Gᵧ|Δy|, где G — максимальные модули соответствующих разностей на пути. Для Gₓ=20, Gᵧ=10 и сдвига (0,1; 0,2) получаем не более четырёх уровней яркости, или 4/127,5 после нормировки. На границе заполнения кадра нужна отдельная оценка скачка.

## 7–12. Геометрия детектора, плиток и рамок

**7. Как получить наибольший масштаб при дискретном бюджете YuNet?** При c столбцах по 32 пикселя и B ячейках доступно floor(B/c) строк. Масштаб равен min(32c/w,32 floor(B/c)/h). Первый аргумент растёт, второй убывает, поэтому максимум достигается в точке пересечения или у соседнего целого c. Двоичный поиск даёт O(log C) вместо O(C). После него применяется ограничение длинной стороны. Это обоснование текущего rectangle_shape.

**8. Увидит ли детектор лицо заданного размера после уменьшения?** Для горизонтального размера d нужно d·rw/w≥m, для вертикального d·rh/h≥m. При кадре 1920×1080 и содержимом 832×468 масштаб в обоих направлениях 13/30. Чтобы получить хотя бы 16 пикселей, сторона исходного лица должна быть не меньше ceil(16·30/13)=37 пикселей. Это необходимое геометрическое условие, не гарантия обнаружения.

**9. Какое перекрытие плиток гарантирует, что лицо не разрежет стык?** Начало объекта длины d помещается в плитку длины T на отрезке длины T−d. Чтобы между допустимыми отрезками не было разрывов, шаг H≤T−d, то есть перекрытие ≥d. Для T=640 и d=96 максимальный шаг 544. Условие по обеим осям и последняя плитка у границы обеспечивают геометрическое покрытие.

**10. Как распределить ограниченное время повторной детекции между областями?** Для непересекающихся областей с независимыми аддитивными выгодами gᵢ и целочисленными стоимостями cᵢ решаем рюкзак: Fᵢ(b)=max(Fᵢ₋₁(b),gᵢ+Fᵢ₋₁(b−cᵢ)) при допустимой стоимости. При бюджете 10, стоимостях (6,5,5) и выгодах (10,8,8) оптимальны две последние области: 16 вместо 10 у жадного выбора по отношению. Для перекрывающихся областей выгоду общих лиц нельзя сложить дважды.

**11. Какое движение рамки само по себе разрывает трек по IoU?** Для двух равных рамок ширины w с одним горизонтальным смещением d≤w имеем IoU=(w−d)/(w+d). Условие IoU≥τ эквивалентно d≤w(1−τ)/(1+τ). При w=80 и τ=0,35 граница около 38,52 пикселя. При изменении масштаба или движении по диагонали эта одномерная граница уже не точна.

**12. Когда пару положительных рамок можно исключить из NMS до расчёта пересечения?** Если площади A≤B, то пересечение ≤A, объединение ≥B. Следовательно IoU≤A/B. При строгом подавлении IoU>τ сравнение можно пропустить, когда A≤τB. При A=40, B=100 и τ=0,4 даже вложенная рамка не пересекает строгий порог. Для реализации в плавающей точке нужна осторожность на границе равенства.

## 13–18. Численная математика ядра

**13. Какова безопасная глубина знакового INT8 dot-product?** Для значений от −128 до 127 наибольший положительный член равен 16 384. При int32 и нулевом смещении K≤floor((2³¹−1)/16 384)=131 071. С известным смещением b достаточна граница K·16 384+|b|≤2³¹−1. Для схемы с промежуточной компенсацией надо отдельно проверить каждую промежуточную сумму.

**14. Как перенести ошибки квантования на скалярное произведение?** Раскрытие (a+e)·(b+f) даёт |Δ|≤‖a‖‖f‖+‖b‖‖e‖+‖e‖‖f‖. Для единичных векторов и ‖e‖,‖f‖≤0,01 оценка равна 0,0201. Для неодинаковых норм весов и активаций надо сохранить первые два множителя; одна средняя ошибка по компонентам такой гарантии не даёт.

**15. Какой масштаб оптимален для уже выбранных целых кодов?** Минимизация Σ(wᵢ−sqᵢ)² по s даёт s=(q·w)/(q·q). При требовании s≥0 берём max(0,s); если q=0, масштаб на результат не влияет. Пример w=(0,9; 2,1), q=(1; 2) даёт 1,02. Это точный шаг оптимизации при фиксированных кодах. После их пересчёта требуется новая проверка ошибки.

**16. Когда линейный слой и BatchNorm можно слить точно?** При фиксированных статистиках вывода α=γ/√(v+ε). Для y=Wx+b получаем W′=diag(α)W и b′=α⊙(b−μ)+β. Результат алгебраически тот же, а отдельный проход исчезает. Если после слияния веса квантуются, ошибку повторного округления измеряют отдельно. Эта формула не заменяет LayerNorm с зависимыми от входа статистиками.

**17. При каком ранге факторизация проекции действительно уменьшает число умножений?** Матрица m×n стоит mn на одну строку. Два множителя ранга r стоят r(m+n); экономия при r<mn/(m+n). Для 64×256 имеем r<51,2. При r=38 стоимость 12 160 вместо 16 384, экономия 25,78%. Это счёт операций; фактическая задержка зависит от ядра и памяти.

**18. Когда выгодно разреженное вычисление геометрии?** Пусть N позиций, m прошли порог, U уникальных соседей 3×3, стоимость проекции P, регрессии R, сборки списка H. Плотный путь стоит N(P+R), разреженный — UP+mR+H, если проекция соседа вычисляется один раз. Для N=1000, m=20, U=120, P=4, R=3 получаем 540+H против 7000; безубыточность при H<6460 условных единиц. При повторном вычислении соседей U заменяется фактическим числом обращений, вплоть до 9m.

## 19–24. Как объединять несколько фотографий человека

**19. Какой единичный шаблон минимизирует суммарное квадратичное расстояние до видов?** Раскрытие Σwᵢ‖u−xᵢ‖² при ‖u‖=‖xᵢ‖=1 сводит задачу к максимуму u·r, r=Σwᵢxᵢ. По Коши оптимум u=r/‖r‖. При r=0 единственного решения нет; для зачисления разумно вернуть неопределённость.

**20. Как выбрать лучшую именно наблюдавшуюся фотографию без матрицы n×n?** В предыдущей задаче ограничиваем u множеством xⱼ. Тогда j*=argmaxⱼ xⱼ·r. Один проход строит r, второй оценивает все виды. Это O(nd) вместо O(n²d), при той же взвешенной косинусной целевой функции.

**21. Как оценить разброс видов без перебора всех пар?** При pᵢ≥0 и Σpᵢ=1 имеем Σᵢⱼpᵢpⱼ‖xᵢ−xⱼ‖²=2(1−‖Σpᵢxᵢ‖²). Если длина среднего 0,8, среднее квадратичное расстояние двух независимых выборок видов равно 0,72. Это проверяемый смысл показателя согласованности шаблона.

**22. Сколько независимых фотографий фактически осталось после взвешивания?** При одинаковой дисперсии независимых ошибок дисперсия взвешенного среднего равна σ²Σpᵢ². Эффективный размер n_eff=1/Σpᵢ². При весах (0,8; 0,1; 0,1) получаем 1,515 вместо трёх. Для кадров одного видео корреляция дополнительно уменьшает информацию.

**23. Какие веса оптимальны при коррелированных ошибках снимков?** Минимизируем pᵀΣp при 1ᵀp=1. Для положительно определённой ковариации множитель Лагранжа даёт p=Σ⁻¹1/(1ᵀΣ⁻¹1). Для независимых дисперсий 1 и 4 веса 0,8 и 0,2, дисперсия 0,8 вместо 1,25 при равных весах. Если нужны неотрицательные веса и формула дала отрицательные, решаем квадратичную задачу на симплексе.

**24. Насколько один плохой вид может повернуть хороший шаблон?** Пусть сумма хороших видов имеет длину R, а норма добавки ≤e<R. Максимальный угол между r и r+δ задаёт касательная из начала к шару радиуса e вокруг r: sin θ≤e/R. Для R=4 и e=1 угол ≤14,48°. При e≥R направление может стать неопределённым.

## 25–30. Поиск среди десятков тысяч шаблонов

**25. Как перевести косинусный порог в радиус поиска?** Для единичных векторов ‖q−x‖²=2−2s. Порог s≥0,8 эквивалентен радиусу ≤√0,4≈0,63246. Это позволяет проверять косинусный поиск эталонным поиском по евклидову расстоянию.

**26. Как гарантировать, что приближённый рейтинг не потеряет точный top-k?** Если |ŝᵢ−sᵢ|≤ε, а c — kth приближённая оценка, любой объект с ŝᵢ<c−2ε имеет точную оценку <c−ε; как минимум k объектов имеют точную оценку ≥c−ε. Поэтому сохраняем все ŝᵢ≥c−2ε, включая равенство. Разность 2ε учитывает две независимо возможные ошибки, одной ε недостаточно.

**27. Когда можно завершить dot-product после части координат?** Пусть P — уже посчитанное произведение, a и b — нормы непросмотренных хвостов. Тогда s≤P+ab. При P=0,35, a=0,4, b=0,5 верхняя граница 0,55; кандидат не достигнет текущей пятой оценки 0,56. Равенство на пороге требует учёта правила сортировки совпадений.

**28. Как отбросить целую сферическую группу?** Пусть все шаблоны находятся на угловом расстоянии ≤r от единичного центра c, а θ=arccos(q·c). По неравенству треугольника максимальный возможный косинус равен не более cos(max(0,θ−r)). При θ=60°, r=15° граница 0,7071; группа не улучшит порог 0,75.

**29. Как оценить ошибку INT8-кандидата из шага квантования?** Если нет клиппинга и каждая из D координат округлена с шагом Δ, то ‖e‖≤√D·Δ/2. Для единичного запроса |q·e|≤√D·Δ/2. При D=512 и Δ=0,001 ошибка ≤0,01132. Это граница до повторной нормировки; если квантовали обе стороны, используем №14.

**30. Когда результат проходной устойчив и по оценке, и по отрыву?** Пусть все оценки известны с ошибкой ε. Для включающего порога t и минимального отрыва m достаточны ŝ₁−ε≥t и ŝ₁−ŝ₂−2ε≥m, причём нижний отрыв должен быть строго положительным для единственности. При (0,81; 0,76), ε=0,01, t=0,79, m=0,025 оба условия выполнены. Для меньшего отрыва нужен точный пересчёт или отказ от решения.

## 31–36. Проверка точности и цена ложного допуска

**31. Как посчитать AUC при совпадающих оценках?** AUC=P(S₊>S₋)+½P(S₊=S₋). Для положительных оценок (0,8; 0,5) и отрицательных (0,5; 0,2) есть три победы и одна ничья; AUC=0,875. Сортировка и объединение одинаковых оценок дают тот же результат без полного попарного массива.

**32. Как выбрать порог при заданном эмпирическом FAR?** При n₋ отрицательных парах и бюджете f допускается не более floor(f n₋) ложных допусков. Сортируем оценки по убыванию и добавляем целые группы равных значений. Выбираем допустимую группу с максимальным числом истинных допусков, при равенстве — меньший FP. Состояние «отклонить всех» всегда достижимо. Это выбор на калибровке; проверка выполняется на независимой выборке.

**33. Сколько отрицательных сравнений нужно, чтобы ноль ошибок имел смысл?** При независимых испытаниях с фиксированным порогом P(0 ошибок)=(1−p)ⁿ. Односторонняя верхняя граница 95% равна 1−0,05^(1/n). Для границы ≤10⁻⁴ нужно ceil(log(0,05)/log(0,9999))=29 956 отрицательных сравнений без ошибок. Подбор порога на этих же сравнениях нарушает предпосылку.

**34. Как меняется риск при поиске по всей базе?** Если вероятность ложного совпадения с одной записью p, то без предположения независимости P(хотя бы одно)≤min(1,Np). При независимости и одинаковом p точное значение 1−(1−p)ᴺ. Для N=10 000, p=10⁻⁵ это соответственно ≤10% и примерно 9,52%. У реальной базы надо измерять ложные идентификации целыми поисковыми запросами.

**35. Как получить порог из цены ошибки и частоты посетителей?** Для плотностей оценки f₁ при своём и f₀ при чужом, априорной доли своих π, сравниваем отношение f₁/f₀ с C_FA(1−π)/(C_FR π). При π=0,1 и цене ложного допуска в 20 раз выше ложного отказа граница отношения правдоподобия равна 180. Это не число на шкале косинуса; перевод требует калибровки.

**36. Как оценить точность, если один человек дал тысячу похожих кадров?** При целевой метрике «средний человек» сначала считаем долю правильных решений aᵢ внутри личности, затем усредняем по личностям. Для двух людей с результатами 990/1000 и 0/1 получится (0,99+0)/2=49,5%, тогда как покадровое значение 990/1001≈98,9%. Оба числа отвечают на разные вопросы; выборку для переноса на новых людей разделяют по личности.

## 37–42. Стабильность видеотреков

**37. При каком дрейфе можно переиспользовать прежнего победителя?** Для единичного шаблона |(q′−q)·x|≤‖q′−q‖=δ. Старый победитель с отрывом g остаётся единственным при g>2δ. Порог допуска также сохраняется, если старая оценка минус δ остаётся выше порога. Гарантия требует верхней границы дрейфа эмбеддинга; IoU рамок сам её не доказывает.

**38. Как из скорости дрейфа получить максимальный срок кэша?** Если доказано δ≤v h за h кадров, то сохраняем ранжирование при h<g/(2v). Для g=0,12 и v=0,01 максимальное целое h=5: на шестом кадре возможна ничья. При смене личности предположение о скорости нарушено, поэтому гарантия заканчивается.

**39. Как распределить бюджет обновления между треками?** Пусть цена устаревания в кадре возраста a равна cᵢa, период обновления Tᵢ, частота fᵢ=1/Tᵢ. При равномерных фазах средняя цена cᵢ(Tᵢ−1)/2. Минимизируем Σcᵢ/(2fᵢ) при Σfᵢ=B. Получаем fᵢ=B√cᵢ/Σ√cⱼ до ограничений частоты. При ценах 9 и 1 доли бюджета 3/4 и 1/4; целые периоды требуют отдельного расписания.

**40. Как совместить предсказанную и измеренную координату лица?** Для независимых несмещённых ошибок с дисперсиями P и R минимум средней квадратичной ошибки даёт K=P/(P+R), x′=x+K(z−x), P′=PR/(P+R). При x=100, z=110, P=9, R=16 имеем K=0,36, x′=103,6 и P′=5,76.

**41. Почему ближайшая пара не всегда правильно распределяет лица по трекам?** При матрице затрат [[1,2],[2,100]] жадный выбор минимума 1 оставляет стоимость 100, итого 101. Перестановка даёт 2+2=4. Для n треков минимизируем сумму по взаимно однозначным назначениям; задача решается венгерским алгоритмом за O(n³). Фиктивные назначения нужны, если допустим пропуск.

**42. Во сколько раз три подтверждения снижают ложные допуски?** При независимых кадрах риск p³. Если с вероятностью r возникает общая причина, которая даёт ложный допуск на всех трёх кадрах, а иначе кадры независимы с риском p, получаем r+(1−r)p³. При r=0,001, p=0,01 это 0,001000999. Куб покадрового риска нельзя подставлять без проверки зависимости.

## 43–48. Очереди, ресурсы и задержка

**43. Сколько запросов успеют начать вычисление до дедлайна?** При одновременном поступлении, c свободных работниках и постоянном времени s старты происходят в 0,s,2s,… Строгий старт до D>0 даёт не более c·ceil(D/s) запросов. При двух работниках, 50 мс и бюджете 250 мс — 10 стартов. Включение равенства на границе изменило бы ответ.

**44. Что меняет очередь между декодированием и моделью?** При отдельных ресурсах с временами d и m для N одинаковых кадров двухступенчатый конвейер занимает d+m+(N−1)max(d,m). При d=8, m=40, N=10 получаем 408 мс вместо 480 последовательных. Если стадии конкурируют за одно ядро, предположение о параллельных ресурсах надо проверить замером.

**45. Как оценить предел потока запросов при смеси кадров?** Для одного последовательного работника условие нагрузки λE[S]<1. При 80% запросов по 20 мс и 20% по 100 мс E[S]=36 мс. Для двух равномерно загруженных работников необходима λ<55,56 запросов/с. Из этого не следует гарантия p95; пики могут давать очередь и ниже предела.

**46. Как разбить четыре работника между двумя независимыми стадиями?** Для k работников декодирования по 20 кадров/с и 4−k работников модели по 12 кадров/с поток равен min(20k,12(4−k)). Перебор k=1,2,3 даёт 20,24,12. Оптимум — 2+2, хотя декодирование само по себе быстрее.

**47. Какие кадры сохранить, если завершить все к срокам невозможно?** Для независимых задач на одном работнике, готовых в момент 0, с одинаковой ценностью, сортируем по дедлайну. При превышении очередного дедлайна удаляем самую длинную из принятых задач: это освобождает максимум времени при потере ровно одной задачи. Для длительностей (4,2,2) и сроков (4,4,5) останутся две короткие, обе завершатся вовремя. При разных ценностях эта стратегия уже не гарантирует оптимум.

**48. Когда пакетная обработка проигрывает одиночной по задержке?** При заполнении пакета b пуассоновским потоком λ средний запрос ожидает (b−1)/(2λ) до заполнения, если таймера нет и работник свободен. При b=8 и λ=40/с это 87,5 мс ещё до инференса. Даже мгновенная модель не выполнит средний бюджет 50 мс в этой политике. Нужен меньший пакет или таймер.

## 49–54. Как доказать, что изменение полезно

**49. Каков потолок ускорения всего запроса при ускорении одного ядра?** По Амдалу T′/T=(1−p)+p/s. Если участок занимает 30% и ускорен в 4 раза, T′/T=0,775, ускорение всего запроса 1,29×. Даже бесконечно быстрый участок дал бы лишь 1,43×.

**50. Реален ли выигрыш классификатора на одних и тех же парах?** Берём только несогласные случаи. Если новая версия исправила 12 ошибок и добавила 2, то при симметричной нулевой гипотезе двусторонний точный тест Макнемара даёт 2·(1+14+91)/2¹⁴≈0,01294. Решения должны быть парными, а пары — независимыми; серии кадров одного человека так считать нельзя.

**51. Сколько парных прогонов нужно для заданной точности времени?** Для независимых парных разностей с оценкой стандартного отклонения σ приближённая полуширина 95% интервала равна 1,96σ/√n. При σ=2 мс и цели 0,5 мс получаем n≥62. Это расчёт для планирования; окончательный интервал при неизвестной дисперсии использует t-критическое значение или подходящую повторную выборку.

**52. Сколько информации несут сто соседних видеокадров?** При стационарной корреляции ρᵏ дисперсия среднего равна σ²/n · [1+2Σₖ₌₁ⁿ⁻¹(1−k/n)ρᵏ]. Отсюда n_eff=n/[выражение в скобках]. При n=100, ρ=0,9 получаем около 5,81 независимого наблюдения. Подставлять 100 в формулу независимой стандартной ошибки слишком оптимистично.

**53. Скольких запросов достаточно хотя бы для наблюдения верхних 5% задержек?** Для независимых задержек из непрерывного распределения вероятность не увидеть ни одного значения выше истинного p95 равна 0,95ⁿ. Чтобы она была не выше 5%, нужно n≥59. Это гарантирует только шанс увидеть хвост, а не точно оценить его квантиль.

**54. Можно ли заявить «точность сохранилась», если на тесте нет ни одного расхождения?** Для n независимых репрезентативных пар старая/новая версия без расхождений дают одностороннюю верхнюю границу риска расхождения 1−0,05^(1/n). При n=15 это 18,10%, при n=3000 — 0,0998%. Побитовое равенство конкретных выходов установлено точно; перенос на популяцию требует обоснованной выборки. Совпадение версий одновременно не доказывает правильность их общего ответа.
